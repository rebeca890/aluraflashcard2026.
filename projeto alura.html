HTML

Para que serve a tag <main>?

Passe o mouse para responder

Resposta

Ela serve para identificar o conteúdo principal e exclusivo da página. Não deve incluir elementos repetidos como menus, barras laterais ou rodapés.

CSS

Qual a diferença entre ID e Class?

Passe o mouse para responder

Resposta

O ID é único e só pode ser usado em um único elemento da página. A Class é reutilizável e pode ser aplicada em vários elementos.

JavaScript

Qual a diferença entre let e const?

Passe o mouse para responder

Resposta

Variáveis criadas com let podem ter seu valor reatribuído depois. Já as criadas com const são constantes e não mudam de valor.
